Web for [GoNoteLM](https://github.com/gonotelm-lab/gonotelm)

## Test Commands

- `npm run test:unit`：运行 Vitest（MSW mock，默认禁止真实网络请求）。
- `npm run test:unit:watch`：本地 watch 模式执行单元/组合测试。
- `npm run test:ci`：CI 场景执行 mock 驱动测试。
